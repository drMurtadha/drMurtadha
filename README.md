My academic work connects artificial intelligence, networked sensing and autonomous systems with research, teaching and practical decision support.

## Research expertise

Artificial Intelligence · Wireless Sensor Networks · Internet of Things · Heritage Microclimate Monitoring · Network Communication · Intelligent Decision Support · Autonomous Systems

I am interested in how sensing, communication and intelligent systems support reliable decisions in challenging environments, including built heritage and underwater networks.

## Selected technical projects

- **[FC Abstract Review Assistant](https://github.com/drMurtadha/fc-abstract-review-assistant)** — Bilingual thesis-abstract review application using React, Vite and an Apps Script integration. Rule-based checks support reviewer judgment; the tool does not automatically approve abstracts.
- **[Thesis-to-Book Transformation Engine](https://github.com/drMurtadha/thesis-to-book-engine)** — Interactive Malay-language manual for developing a thesis into a scholarly or popular knowledge book, with search and reading progress.

These repositories document their own setup and scope; inclusion here does not imply a production deployment.
